# UML классов КТ3

Актуальная модель Java 17 для процесса «Контроль готовности этапа иммерсивной кампании к согласованию».

- `classes.puml` — единый исходник PlantUML с 11 представлениями.
- `classes.png` — все представления в одном PNG, в порядке исходника.
- `classes-01.png` — общая схема физических пакетов `core`, `main` и `Main`.
- `classes-02.png`–`classes-09.png` — тематические листы пакета `core`.
- `classes-10.png`–`classes-11.png` — пакет `main`, внешние порты и точка входа.

Показаны все 42 производственных типа: 27 обычных классов, 11 record и 4 интерфейса. Конструкторы, стандартные методы record, часть однотипных методов чтения record и приватные вспомогательные методы опущены для читаемости; поля, бизнес-методы, типы и видимость соответствуют коду. Переопределение Task/ReworkTask, реализация BriefRule и ResultPresenter, ассоциации с кратностями и агрегация CampaignData раскрыты на отдельных листах. Вспомогательные типы тестов в модель приложения не входят.

Рендер: PlantUML 1.2025.10, встроенный движок Smetana; Graphviz не требуется:

```sh
java -Djava.awt.headless=true -jar plantuml-1.2025.10.jar -charset UTF-8 -tpng classes.puml
```

Команда создаёт 11 отдельных PNG. `classes.png` объединяет их без изменения масштаба; в отчёте листы вставлены по отдельности для чтения на портретных страницах А4.
