Файлы `.drawio` содержат все листы соответствующей схемы. В `.bpmn` показаны менеджер, программная система, восемь задач и 11 входных объектов данных. Программа использует ту же модель данных и операции, что описаны в отчёте.

Установленная среда: IntelliJ IDEA Ultimate 2025.2.4, сборка IU-252.27397.103. Процедурная версия запускается из терминала.

Для перевода использована научная статья Kabir и Kang (Information, 2024): [статья](https://doi.org/10.3390/info15120758), [полный PDF](translation/original.pdf), [перевод аннотации, обсуждения и заключения](docs/translation.md). Библиографические записи корпоративных блогов заменены книгами; утверждения о внешних ключах и транзакциях сопровождаются ссылкой на документацию PostgreSQL 17.
