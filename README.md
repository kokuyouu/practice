# Работа агентства иммерсивного маркетинга

Учебная практика, РТУ МИРЭА, Институт информационных технологий, кафедра игровой индустрии, 2026.

Обучающийся: Пестряков Максим Александрович, группа ИКБО-31-24.

Проект посвящён учёту заказов агентства: от брифа клиента до согласования и передачи иммерсивной рекламной кампании. Форматы заказов включают интерактивные пространства, инсталляции, мероприятия и цифровые презентации.

## Структура

| Каталог | Назначение |

| `docs/` | Разделы отчёта КТ1, источники, перевод и отчёт Word |

## Текущее состояние

Подготовлены исследовательские материалы первой контрольной точки. Описан типовой учебный процесс; обследование конкретной организации не проводилось. Основные алгоритмы и база данных будут реализованы на последующих этапах.

Планируемые средства: Python 3.12+, Java 17+, PostgreSQL 17, IntelliJ IDEA и Git.

## Проверка запуска

Из корня репозитория:

```sh
python3 cmd/hello.py
java internal/Hello.java
```

Общая проверка:

```sh
sh scripts/check-environment.sh
```

При нескольких установленных версиях можно указать путь к Python и Java через `PYTHON_BIN` и `JAVA_BIN`. Проверка выводит версии средств; подключения к базе и реализации бизнес-логики пока нет.
