# Процедурная реализация КТ2

Программа проверяет обязательные поля брифа и готовность этапа к согласованию, находит просроченные задачи с упорядочиванием по сроку и формирует сводку по заказу.

## Язык и версия

Python 3.13.2.

## Зависимости

Используется только стандартная библиотека Python. Внешних зависимостей нет.

## Запуск

Из каталога `src`:

```sh
python3 main.py
```

Предварительная сборка не требуется.

## Пример входных данных и ожидаемого вывода

Входные данные: [sample_data.json](sample_data.json). Файл содержит записи клиентов, заказов, сотрудников, этапов, задач, материалов, версий, согласований и замечаний, а также связи между ними.

Запуск для заказа O1 на дату 31.10.2026 из каталога `src`:

```sh
python3 main.py --data sample_data.json demo --order O1 --as-of 2026-10-31
```

## Оценки сложности

Проверка готовности этапа: `O(N²)` в худшем случае при суммарном числе записей `N`. Для каждой обязательной задачи просматриваются связи с материалами; для новых материалов — версии и замечания. Вложенные циклы соответствуют блок-схеме отчёта.

Поиск просрочек: `O(N log(N+1))` в худшем случае, где `N` — суммарное число заказов, этапов и задач. Списки заказов и этапов сортируются, принадлежность проверяется бинарным поиском `bisect_left`, результат сортируется по `(deadline, task_id)`. Переменные по размеру хеш-индексы в этих двух алгоритмах не используются. Дополнительная память — `O(N)`; загрузка и валидация JSON предшествуют вызову алгоритмов.
